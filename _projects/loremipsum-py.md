`loremipsum-py` is an open-source Python library maintained by the Lorem Ipsum Consortium for
dolor sit amet estimation in observational and experimental settings. The package provides a
unified interface to a wide class of semiparametric estimators, with native support for
cross-sectional, panel, and clustered data structures.

My contributions span the core estimation engine, performance, and documentation.
The primary work — merged across five pull requests — introduced the full consectetur estimator
family described in Lastname (2021), along with the numerical infrastructure needed to make
them practical at scale.
